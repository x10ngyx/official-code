# Entry points

`prepare_wan22.sh DESTINATION` checks out unpatched Wan2.2@42bf4cf. `validate_source.py` verifies the source and package hashes. `run_t2v_a14b.sh` runs one baseline or DiCache video; its Python entry supports `--dry-run`. `audit_baseline.py` compares common upstream locks and SeaCache’s disabled numerical path. See the package README for commands.
