# VBench evaluation resource results

Large downloaded metric resources and smoke-test outputs must live outside the
repository. This directory may contain local symlinks to those external
bundles; only this README is versioned.

Typical local entries include a validated VBench checkpoint bundle and an
official CPU scoring smoke test containing logs, manifests and independent
validation.

The OSS packaging result may also be linked here locally; it contains the
validated ZIP64 archive, SHA256 metadata and upload manifest.
