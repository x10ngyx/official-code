# TeaCache4Wan22 VBench coverage threshold scan result

This directory is generated by
`experiments/threshold_scan_vbench8_t2v_a14b/run_scan.sh`.

- `calflops_profile.json`: locked real-shape high/low DiT Calflops profile.
- `runs/<sample_id>/`: MP4, complete timing, TeaCache decision trace, manifest,
  and raw log for the baseline and every threshold.
- `worker_status/*_runtime.json`: one-time persistent-pipeline initialization
  time, physical GPU identity, assignment, and resumable worker progress.
- `analysis/<threshold>/performance/`: validated per-video inference latency,
  actual-trace estimated DiT TFLOPs, and ratio-of-sums speedups.
- `analysis/<threshold>/video_metrics/`: canonical per-frame/per-video
  PSNR/SSIM/LPIPS against the same-prompt no-cache reference.
- `analysis/vbench_reference/` and `analysis/<threshold>/vbench_candidate/`:
  official VBench per-dimension outputs and 16-dimension subset score.
- `scan_summary.json` and `scan_summary.csv`: one aggregate row per threshold.
- `per_video_summary.csv`: one complete prompt/threshold row with inference
  time, TFLOPs, PSNR, SSIM, and LPIPS.
- `target_thresholds.json`: nearest measured and linearly interpolated threshold
  diagnostics for 1.8x, 2.4x, and 3.0x.
- `VALIDATION.json`: completion, identity, count, and monotonicity audit.

Warm-up generations and GPU telemetry are retained for audit but are excluded
from every reported speed and quality aggregate.
