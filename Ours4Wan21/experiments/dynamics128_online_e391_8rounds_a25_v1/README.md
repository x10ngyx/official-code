# Dynamics128 e391 four-GPU online IQL

User explicitly selected the original Dynamics128 **epoch 391** checkpoint (mode `sea7_dynamics_raw_sea128`). Eight rounds × 100 online trajectories; A2/A3 midpoint profile tau=.85, beta=2.5, weight_max=75. Actor/critic LR4e-5/1e-4, 5 critic warmup + 20 joint epochs and e11–20 selection, accumulated replay and original normalizer.

`prepare_cache.py` checks the completed 150000×135 offline transition cache against the exact checkpoint manifest and checksum, original feature index and twelve deterministic feature rows. It exercises real e391 policy sampling with synthetic small latent inputs, exact parity with the offline causal feature extractor, online replay conversion, critic/actor updates and checkpoint restoration on CPU. Synthetic outputs never enter production replay or weights. Existing caches are reused. If preflight rejects missing/corrupt caches, stop rather than substituting SEA7-only states or rebuilding with a different feature definition.

Feature flow: offline cached 128 Dynamics + 7 SEA features -> frozen 135D state normalizer; each online worker uses current/past candidate latents with the same FP16-then-FP32 quantization and commits executed actions -> trace carries full 135D pre-action states -> per-round replay/transitions.pt holds 5000 states and successors -> cumulative IQL. R1 includes 120000 offline train transitions plus 5000 new transitions. Fixed actor-selection support is freshly constructed from Dynamics128 offline train states. No baseline or future latent enters features; no raw latent re-extraction is required for existing offline cache.

`run.sh prepare` freezes the run after cache preflight; `launch.sh` executes it. Train prompt pool is the same offline 800 train prompts, native baselines reused, validation/test excluded. Targets1.5–3.5×. R4/R8 use the frozen20 VBench50 prompts, K23/29/35 for nominal1.8/2.4/3.0×, compare e391 with selected online weights, native baselines reused, PSNR/SSIM/LPIPS and component latency/TFLOPs; no VBench scoring.

Results and cache audit live under `/mnt/hdd/xiongyuxiang/tmp/exp/ours21_dynamics128_e391_online_offline800_8rounds_a25_v1` and its `_setup` sibling, linked in experiment_results. Weights use the matching models directory. `timing_estimate.json` adjusts prior wall-time estimates with measured Dynamics128 training/feature overhead; estimates are not a deadline or speed guarantee.
