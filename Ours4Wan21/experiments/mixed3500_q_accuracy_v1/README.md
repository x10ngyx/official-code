# Q versus realized RGB PSNR

run.py evaluates selected e374/e358 critics on their own60 rollout traces each, CPU only. Uses raw135-dim recorded states and checkpoint normalizer; Q=min(Q1,Q2), selected action (reuse=1). Verify cond/uncond shared states/actions then count each step once. Gamma1/reward_scale1, terminal-only absolute RGB PSNR means realized return at every step equals final RGB PSNR. Primary: free actor_mask steps; report trajectory-equal mean error, mean absolute step error and sqrt(mean per-trajectory step MSE). Also mean-Q per trajectory bias/MAE/RMSE, first-free prediction and terminal diagnostics. All50 steps retained in CSV with mask. One realized continuation per state, not proof of error in conditional expected return, and IQL implicit continuation can differ from actor rollout. Comparing own rollouts uses same prompts/K but different states; no causal claim. No YUV-Q subtraction.
Outputs: suite/analysis/q_accuracy/, CSV/PNG/SVG/REPORT/VALIDATION; source hashes and policy probability replay confirm state/checkpoint alignment.
