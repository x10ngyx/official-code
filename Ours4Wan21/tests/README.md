# CPU RL tests

Run conda run -n wan2.2 python -m unittest discover -s tests -v from Ours4Wan21. Tests cover exact local kernel hashes, all K values, train/inference state equality, branch-specific cache behavior, scalar dimensions, invalid data, actor masking, backward updates and real sibling forward equivalence on a tiny CPU model. No production model weights or GPU tasks.

test_overhead_workflow.py covers exact Calflops predictor counts, per-video reset/forced-zero, CPU durations and mock CUDA event finalization, deterministic random subsets, native val/test isolation, checkpoint ranking and remote-root propagation.

`test_latent_groups.py` covers ten-group causality, single/joint FP16 equivalence, archive identity/actions, official SEA formula, Wan21 step32 continuity, all-group controller parity and real IQL backward updates. Full cache/train/save/load integration is `experiments/latent_groups_v1/validate.py`; production checkpoints are never generated by that smoke entry.
